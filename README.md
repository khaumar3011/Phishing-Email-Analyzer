# Phishing Email Analyzer

A Python tool that analyzes .eml email files for common phishing indicators.

## Features
- Extracts email headers (From, Reply-To, Subject, Date)
- Detects spoofed Reply-To addresses
- Flags urgency words in subject lines
- Extracts and checks URLs for link shorteners
- Identifies dangerous attachment types

## Usage
```bash
python3 analyzer.py youremail.eml
```
